# GeoShelter

GeoShelter загружает объекты заданных категорий из Wikimapia API и сохраняет их в KML-файлы. Проект можно запускать через графический интерфейс PyQt6 или из командной строки. Полученные файлы можно открыть, например, в Google Earth или другой программе с поддержкой KML.

Версии для ОС:
  Linux: https://github.com/userpy/geoshelter/raw/refs/heads/main/build/geoshelter_0.1.0_amd64.deb
  
  Windows: https://github.com/userpy/geoshelter/blob/main/build/windows/GeoShelter.exe
## Возможности

- Выгрузка объектов по ID категорий Wikimapia.
- Обход нескольких страниц API.
- Обход сетки соседних прямоугольных областей: по горизонтали вправо или влево, затем вниз или вверх.
- Сохранение названия, описания и категорий объекта в KML.
- Задержка между запросами для снижения нагрузки на API.
- Объединение нескольких KML в один KMZ с папками по категориям.

## Требования

- Python 3.12 или новее;
- [uv](https://docs.astral.sh/uv/);
- ключ Wikimapia API.

## Установка через uv

Если `uv` ещё не установлен, установите его по [официальной инструкции](https://docs.astral.sh/uv/getting-started/installation/). Для Linux и macOS:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Для Windows PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

После клонирования проекта перейдите в его каталог и синхронизируйте окружение:

```bash
uv sync
```

`uv` автоматически создаст `.venv` и установит версии пакетов из `uv.lock`. Активировать окружение вручную не нужно.

Чтобы инициализировать аналогичный проект с нуля:

```bash
uv init
uv add httpx simplekml python-dotenv loguru PyQt6
```

## Настройка API-ключа

Приложение ищет `.env` в корне проекта:

```dotenv
WIKIMAPIA_API_KEY=ваш_ключ_api
```

Не добавляйте `.env` и API-ключи в систему контроля версий.

## Структура проекта

Код разделён по слоям: бизнес-логика не зависит от PyQt6 и конкретной HTTP-библиотеки.

```text
GeoShelter/
├── src/
│   ├── domain/                       # предметная область
│   │   ├── models.py                   # настройки, модель места и результат
│   │   └── geometry.py                 # bbox и смещение областей по сетке
│   ├── application/                  # сценарии приложения
│   │   ├── download_places.py          # асинхронная и параллельная загрузка
│   │   ├── rate_limiter.py             # лимит запросов для API-ключей
│   │   ├── ports.py                    # контракты HTTP-клиента и KML-writer
│   │   └── errors.py                   # ошибка отмены загрузки
│   ├── infrastructure/               # работа с внешними системами
│   │   ├── wikimapia_client.py         # асинхронный HTTP-клиент Wikimapia
│   │   ├── kml_writer.py               # создание KML-файлов
│   │   └── app_settings.py             # .env, пути и значения по умолчанию
│   ├── presentation/                 # графический интерфейс
│   │   ├── main_window.py              # главное окно и настройки
│   │   ├── download_worker.py          # связь asyncio с PyQt-потоком
│   │   └── download_grid.py            # визуализация сетки областей
│   ├── assets/                       # SVG-иконка приложения
│   ├── main.py                       # точка запуска GUI
│   └── cli.py                        # точка запуска CLI
├── pyproject.toml                       # метаданные, зависимости и entry points
├── uv.lock                              # зафиксированные версии зависимостей
├── .env                                 # API-ключ (создаётся локально)
└── README.md
```

Папки `__pycache__`, `.venv`, `*.egg-info` и созданные KML-файлы не являются частью исходного кода.

## Настройка выгрузки

Значения по умолчанию задаются в `src/infrastructure/app_settings.py`:

| Параметр | Назначение |
| --- | --- |
| `CATEGORY_IDS` | ID категорий Wikimapia, которые нужно выгрузить. |
| `TOP_POINT` | Верхняя левая точка области в формате `[latitude, longitude]`. |
| `BOTTOM_POINT` | Нижняя правая точка в формате `[latitude, longitude]`. |
| `SQUARE_COUNT` | Число областей по горизонтали в каждой строке. |
| `ROW_COUNT` | Число строк областей по вертикали. |
| `VERTICAL_DIRECTION` | Направление строк: `"down"` (вниз) или `"up"` (вверх). |
| `MAX_PAGES` | Максимальное число страниц API на категорию и область. |
| `RESULTS_PER_PAGE` | Число объектов в одном запросе. |
| `REQUEST_DELAY` | Пауза между запросами в секундах. |

Координаты должны удовлетворять условиям:

- широта `TOP_POINT` больше широты `BOTTOM_POINT`;
- долгота `BOTTOM_POINT` больше долготы `TOP_POINT`.

## Запуск GUI

Все команды ниже выполняются из корня проекта, где находится `pyproject.toml`. После `uv sync` запустите GUI через точку входа:

```bash
uv run geoshelter
```

Альтернативный запуск модуля напрямую:

```bash
uv run python src/main.py
```

В окне можно:

- указать API-ключ и ID категорий;
- искать категории Wikimapia по названию или ID через кнопку `📖`;
- задать координаты области;
- настроить число областей по горизонтали и вниз, страниц, объектов и задержку;
- выбрать горизонтальное направление: `→ Право` или `← Лево`;
- выбрать вертикальное направление: `↓ Низ` или `↑ Верх`;
- защитить максимум страниц, число объектов и задержку от случайного изменения кнопкой-замком;
- выбрать каталог для KML-файлов;
- сохранить введённые параметры для следующих запусков;
- вернуть исходные значения кнопкой `По умолчанию`;
- следить за прогрессом и остановить загрузку.

Вкладка `Объединение KML в KMZ` собирает выбранные KML-файлы в один KMZ. ID
категории определяется из имени `wikimapia_<ID>_...`; его можно изменить в таблице.
Одну категорию можно назначить сразу нескольким выделенным строкам.
В блоке `Названия категорий` пары `ID — название` добавляются кнопкой
`+`, а выбранные пары удаляются кнопкой `−`. Кнопка `Применить к указанным файлам`
заменяет ID на заданное название во всех совпавших файлах.
Кнопка `Сохранить категории` запоминает список и автоматически восстанавливает его
при следующем запуске приложения.
Строки можно сортировать по файлу или категории нажатием на заголовок столбца.

API-ключ автоматически подставляется из `.env`, если он там задан. После нажатия `Сохранить настройки` параметры, включая API-ключ, хранятся в локальных настройках текущего пользователя:

- Linux: `$XDG_CONFIG_HOME/GeoShelter/GeoShelter.conf`, а если `XDG_CONFIG_HOME` не задан — `~/.config/GeoShelter/GeoShelter.conf`;
- Windows: `HKEY_CURRENT_USER\Software\GeoShelter\GeoShelter` в системном реестре.

## Запуск из командной строки

Для CLI ключ в `.env` обязателен. Запуск через точку входа:

```bash
uv run geoshelter-cli
```

Альтернативный запуск:

```bash
uv run python src/cli.py
```

Во время работы скрипт выводит в консоль текущую категорию, область, страницу и число сохранённых объектов.

## Сборка DEB-пакета

Сборка выполняется в Debian/Ubuntu Linux. Понадобятся Python 3.12
или новее, `uv` и системная утилита `dpkg-deb`. Установите её:

```bash
sudo apt update
sudo apt install dpkg-dev
```

Затем из корня проекта синхронизируйте окружение и запустите сборку:

```bash
uv sync --frozen
uv run --frozen python build_deb.py
```

Готовый пакет будет создан в каталоге `build/`, например
`build/geoshelter_0.1.0_amd64.deb`. Другой каталог можно указать так:

```bash
uv run --frozen python build_deb.py --output-dir dist
```

Установка и удаление пакета:

```bash
sudo apt install ./build/geoshelter_0.1.0_amd64.deb
sudo apt remove geoshelter
```

После установки приложение доступно в пользовательском меню и командами
`geoshelter` и `geoshelter-cli`.

## Сборка Windows EXE

EXE нужно собирать в Windows: PyInstaller не является
кросс-компилятором и не создаёт Windows-файл из Linux. Нужны
Python 3.12 или новее и `uv`.

В PowerShell из корня проекта синхронизируйте `build`-группу и
запустите сборку:

```powershell
uv sync --frozen --group build
uv run --frozen --group build python build_exe.py
```

Инструменты сборки PyInstaller и Pillow хранятся в `build`-группе
`pyproject.toml`, а их версии фиксируются в `uv.lock`. Скрипт добавит в сборку
ресурсы и создаст один файл `build/windows/GeoShelter.exe`. Python и
зависимости на целевом компьютере не требуются.

Другой каталог результата:

```powershell
uv run --frozen --group build python build_exe.py --output-dir dist
```

```bash
git clone <URL-репозитория>
cd GeoShelter

```

Если `.env.example` отсутствует, создайте `.env` вручную по примеру из раздела «Настройка API-ключа».

## Результат

Для каждой категории и каждой области в текущем рабочем каталоге создаётся отдельный файл. Имя имеет вид:

```text
wikimapia_<category_id>_row_<row>_square_<column>_<top_point>_<bottom_point>.kml
```

Например:

```text
wikimapia_44690_row_1_square_1_[55.83834, 49.20662]_[55.79571, 49.30515].kml
```

Каждая KML-точка содержит название объекта, его координаты, а также доступные описание и категории.

## Возможные ошибки

- `WIKIMAPIA_API_KEY не задан в .env` — проверьте путь к `.env` и имя переменной.
- `SQUARE_COUNT должен быть не меньше 1` — укажите положительное число областей.
- `ROW_COUNT должен быть не меньше 1` — укажите положительное число строк.
- `VERTICAL_DIRECTION должен быть "down" или "up"` — проверьте вертикальное направление.
- `Ошибка координат` — проверьте порядок и взаимное расположение точек.
- `Ошибка запроса` — проверьте API-ключ, подключение к сети и доступность Wikimapia API.
